# LAX360 Academy & Campus Website

A premium, modern Indian international school website and administrative portal built with Next.js 14, React, Tailwind CSS, and Framer Motion.

## Features

- **Public School Portal**:
  - **Persistent Global Navigation Bar**: Pure route-based navigation across Home, About, Programs, Campus Life, Facilities, Admissions, Careers, and Contact.
  - **Cinematic Experience**: Interactive canvas visual scroll engine showcasing campus infrastructure and student life.
  - **Academic Frameworks**: Stage-by-stage curriculum breakdowns (Early Years, Primary, Middle, and Senior Secondary IB/Cambridge).
  - **Student Life & Clubs**: Clubs, societies, and four-house collegiate system.
  - **Admissions Suite**: 3-step enrolment roadmap, evaluation deadlines, and interactive registration with privacy consent tracking.
  - **Careers Portal**: Complete job board with published vacancies, position detail modals, candidate application flows, and local persistence.

- **Administration Portal (`/admin`)**:
  - **Dashboard Overview**: Key metrics, enquiries, events, and calendar management.
  - **Careers Management**: Job posting management, position editor, and candidate dossier review drawer.
  - **Privacy & Consent Governance**: Data rights request desk and consent audit logging.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Language**: TypeScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/lax360linkedin/school_demo.git
   cd school_demo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
